bsh-dbus-adapter

Flash the firmware for the B/S/H/ D-Bus adapter straight from this page. Version {{VERSION}}.

Flash the board on its own, never while it is attached to an appliance. The D-Bus is not guaranteed to be isolated from mains earth, and this page needs a USB cable to your computer. Set the board up here first, then take it to the machine, where it is reachable over WiFi and needs no cable again.
Works in Chrome and Edge on a desktop, which are the browsers that support Web Serial. Firefox and Safari cannot talk to a serial port, and neither can phones.

Updating a device that is already set up? You do not need this page: the firmware updates itself over the network, under Settings → Firmware. Use the installer for the first flash, or to recover a board that no longer answers. It writes the four parts at their own offsets and leaves the space between them alone, so WiFi credentials, the password and stored profiles survive. It also offers to erase the device; say no unless you want to start over.

After flashing

  1. The adapter opens its own network, named after itself: bsh-dbus-adapter-XXXXXX. It is open, with no password.
  2. The setup page appears by itself on most phones. If it does not, browse to http://192.168.4.1/.
  3. Enter your WiFi credentials. The device restarts to join, so the setup network disappears — rejoin your own WiFi and look for the device there, by name in your router or over mDNS.
  4. Connect it to the appliance. It will listen, work out which profile matches what it hears, and offer that.

Nothing is compiled in for your machine: the same image works for everybody, and what the bytes mean comes from a profile you can pick, edit or write on the device.

If you cannot reach it again

Holding the BOOT button for five seconds while the device is running erases the WiFi credentials and the password and reopens the setup network. On the BaSHi that button is switched off on purpose, because there the pin doubles as the bus line and holding it would disturb the appliance.
